## 一、燃油分项

| 分项 | ICAO / EASA | 日本（航空运送事业、涡轮飞机、IFR） |
| --- | --- | --- |
| 滑行油（taxi） | 按出发机场条件与 APU 消耗计 | 第153条未单列；「運航規程審査要領細則」要求计入起飞前用油（转述） |
| 航程油（trip） | 起飞爬升到初始巡航高度（含离场航路）+ TOC 到 TOD（含阶梯爬升 / 下降）+ TOD 到进近开始（含进场航路）+ 进近着陆（EASA AMC1 CAT.OP.MPA.181(b)） | 「着陸地までの飛行を終わるまでに要する燃料の量」 |
| 应急油（contingency） | 计划航程油的 5%，与在目的地上空 1,500 ft 以等待速度飞 5 分钟的油量，取大（EASA (c)） | 告示第319号：航程油的 5%，与在着陆地上空 450 m 待机 5 分钟的油量，取大。运航规程规定了按机修正与航线统计分析的航司，在选定航线上可用 3% |
| 备降油（alternate） | 复飞 + 爬升 + 巡航 + 下降 + 进近到备降场；两个备降场时取较多者（EASA (d)） | 有备降场时含「到最远的备降场」的油 |
| 最后储备油（final reserve） | 涡轮飞机在机场上空 1,500 ft 以等待速度飞 30 分钟（EASA CAT.OP.MPA.181(c)；该 AMC 修订前的文本也写明这个值） | 有备降场：在备降场上空 450 m 待机 30 分钟。无备降场：在着陆地上空 450 m 待机 45 分钟 |
| 附加油（additional） | 应对航路上关键点发动机失效或失压，改飞航路备降场 + 15 分钟等待 | 第153条 第二式：关键点发动机失效或失压后飞到适合机场所需油量 + 在该机场上空 450 m 待机 15 分钟 |
| 额外油（extra / discretionary） | 机长决定 | — |

### 日本 第153条的取法（航空运送事业、涡轮飞机、IFR）

两式取大：

1. **代替空港等を飛行計画に表示する（有备降场）**：
   - ① 航程油 + 到最远备降场的油 + 在该备降场上空 450 m 待机 30 分钟的油 + 应急油；
   - ② 关键点发动机失效或失压后到适合机场的最多油量 + 在该机场上空 450 m 待机 15 分钟的油。
2. **表示しない（无备降场）**：
   - ① 航程油 + 在着陆地上空 450 m 待机 45 分钟的油 + 应急油；
   - 没有可作备降的机场时，①改为：航程油 + 以巡航高度飞 2 小时的油 + 应急油；
   - ② 同上一条的②。

- 非航空运送事业的 IFR 飞机（第153条第6项）：航程油 + 备降油 + 以巡航高度飞 45 分钟的油；不设备降场时去掉备降油。
- **3% 应急油的条件**：据「運航規程審査要領細則」（令和2年10月版，转述，未核对最新版）：
  - 要按机持续监控速度、高度、推力与耗油；
  - 要有一年以上的计划与实际对比统计；
  - 原则上用于大圆距离 4,000 英里以上的航线。

## 二、重量

| 缩写 | 含义 |
| --- | --- |
| OEW / DOW | 使用空重 / 干使用重量 |
| ZFW | 无油重量 = DOW + 业载（旅客、行李、货物） |
| TOW | 起飞重量 = ZFW + 起飞时油量（= 加油量 − 滑行油） |
| LW | 着陆重量 = TOW − 航程油 |
| MZFW / MTOW / MLW / MFC | 最大无油 / 起飞 / 着陆重量、最大燃油容量（结构限制；跑道、爬升梯度等还会进一步限制起飞重量） |

- **轮挡油（block fuel）**：开车前的总加油量，包含滑行油。航程油（trip）只算起飞到着陆。
- **计划时的约束**：TOW ≤ MTOW（及性能限制）、LW ≤ MLW、ZFW ≤ MZFW、油量 ≤ MFC。
- **国内短程宽体机常受 MLW 限制**：起飞重量不能太高，否则落地超重。例如 B772 以 0.85 MTOW 飞羽田→福冈，落地仍超 MLW，见 [validation.md](validation.md) T3 B7。

## 三、SimBrief 预填参数

SimBrief 派遣链接能带的燃油、重量、高度参数：

- **参数名**：`units`、`civalue`、`fl`、`contpct`、`resvrule`、`taxiout` / `taxiin`、`addedfuel`、`pax`、`cargo`、`manualzfw`、`altn` 等。完整列表与格式见仓库根目录的 `simbrief_params.md`。
- **与日本规则的对应**：
  - 应急油：`contpct=0.05`；
  - 最后储备油：`resvrule` 写分钟数，有备降场时 30；无备降场时第153条要求 45 分钟待机，可设 45 并不填 `altn`；
  - 450 m 待机与 1,500 ft 等待是同一高度。
- **本项目现状**：程序目前不发送这些参数（见 [project_state.md](project_state.md)）。
